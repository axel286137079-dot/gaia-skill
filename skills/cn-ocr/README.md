# 中文OCR

本地Tesseract文字提取与词级坐标/置信度；简体/繁体/竖排、单图text/json及目录批量。详见SKILL.md和references/guide.md。

0.1.9是安全恢复版：在保留0.1.5多页TIFF `page_num`修复的同时，恢复同stem冲突消歧、输出全量预检、独占写入、输出根目录身份复核和符号链接拒绝，防止批量任务覆盖已有文件或跟随链接改写其他目标。原词数组/字段和顺序、纯文本及批次接口保持。

官方 Tesseract 当前发布版为5.5.4（2026-10-28，以安全修复为主，官方说明修复17项安全公告；上一版5.5.3发布于2026-07-24），使用5.5.3及以上即可，能升级到5.5.4建议优先。本包不下载模型；只应加载官方渠道的语言包，不应使用来源不明的`.traineddata`，因官方安全公告已确认恶意模型文件可触发内存安全问题——风险面是模型文件而非图片，升级不能替代这条纪律。中文语言包自2018年后未更新，升级不改变中文识别效果。

核心需已安装Tesseract与相应语言包，只有可选样例生成器需已有Pillow。样例须生成到外部不存在的新目录；安装后没有预置normal.png，不能未生成就运行。默认仅尝试明确常见系统字体路径，找不到请--font指定合法本地字体，不广搜私有目录。

批量输出拒覆盖普通文件、目录、链接和摘要；同名异扩展保独立结果。输入内容快照与TIFF完整页验证拒绝清单重定向或部分识别假成功。晚创建竞态受控失败，可能留下本次部分输出；不会删除外来文件或危险回滚。

真实样例记录为固定本机字体/Pillow/Tesseract环境的结果，不保证其他字体/版本像素、字节、分词和置信度一致。回退文件系统能力只在本机模拟，Windows未真实验证；原生解析器和同账号任意目录替换不宣称彻底隔离。
