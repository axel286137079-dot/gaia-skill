# 跨境 Listing 优化

把商品事实整理为目标市场可读的 Listing 草稿，再用离线检查器找出明显的措辞与格式风险。此工具不保证上架、排名或法律合规；不能替卖家确认类目、资质、费用或政策生效日。

## 何时使用

- 卖家提供产品事实、目标站点、语言和目标人群，需要标题、卖点、描述或搜索词草稿。
- 卖家要对已有 Listing 做本地格式检查，并希望看到可逐项修改的结果。
- 商品涉及疗效、儿童用品、锂电池、捆绑品等高风险类目时，仅输出待核实清单，不依据标题自行认定合规。

## 输入与产出

必要输入：产品名称、可核实的材质/规格/功能、目标站点与语言。若缺少品牌授权、测试报告、尺寸或成分，不编造；在草稿中标记“待确认”。

产出应包含：

1. 一份标题草稿、五点描述、商品描述和 Search Terms 候选；不同语言分别成稿，不逐字硬译关键词。
2. 每条与产品事实相关的主张及其输入依据；无法证实的功效、认证、比较和保证性表述须删除或留待人工确认。
3. 离线检查结果与人工复核清单，明确“格式提示”不等于平台审核结果。
4. 对 Amazon 以外的平台，不套用 Amazon 的字段上限或政策日期；按目标平台实时规则重新设置检查阈值。

## 工作流

### 1. 提取事实

区分用户给出的事实、推断和未知。仅将事实用于面向买家的肯定陈述；未知参数不得通过常见产品规格补全。

### 2. 起草与本地化

标题按品牌、核心产品词、关键规格和差异属性组织。五点描述优先说明可验证的用途、适用条件及尺寸。Search Terms 只列与产品相关的同义词，避免品牌侵权、竞品词和无关词。翻译时兼顾目标市场的惯用说法。

### 3. 运行格式检查

```bash
python3 bin/listing_check.py listing.md
python3 bin/listing_check.py listing.md --json --title-max 75 --bullet-max 500
```

美国站 Amazon 非 Media 类目：官方 2026-07-27 标题更新要求不超过 75 字符，Item Highlights 最多 125 字符；Media 和其他站点应先确认类目规则并用 `--title-max` 等参数调整。脚本的其他默认阈值是本地预警值，并非所有国家、类目的统一法律或平台硬上限。

脚本列出的词是“需复核”信号：词是否违规取决于上下文、类目和可证明的依据。不要把命中数量直接当成平台处罚预测。

### 4. 核对政策与发布

- 如果图片或视频包含写实 AI 生成人物，在上传 Amazon 前按官方要求检查 `contains-synthetic-performer` 的 XMP `dc:subject` 标记。
- Amazon 美国站发往 Amazon Business 客户的卖家自配送订单，官方公告自 2026-09-30 起要求 BHDR 至少 90%（14 天滚动）；具体豁免、账户状态仍需在 Seller Central 复核。
- Amazon 的多数单 ASIN 捆绑品扩展规则官方生效日是 **2027-01-11**，不是 2026-09-30；现行消耗品等类目要求需分别核对。授权重包装、特定礼品/相机类及合格 Virtual Bundles 有例外，不要仅凭本工具提前下架或清理库存。
- 美国站若新建或编辑官方列出的四组危险品相关类目 Listing，自 2026-10-26 起须回答新增问题；答案必须依据实际型号和资料，不能由标题猜测。
- 增强安全类目的商业责任险与中国大陆卖家 AIA 新保单要求官方公告拟于 2026-11-02 生效；须看具体类目、主体和卖家后台通知，不由本工具给出投保建议或保费估计。
- 费用、关税、物流时效、促销截止日和进口责任有独立规则且经常变化。报价或上架前，应在目标站点 Seller Central、承运商和海关官方页面核对，不使用历史示例费率直接算利润。

上述来源与核对边界见 `references/official-policy.md`。用户若要求具体法律、保险、关税或费用结论，只能基于其目标站点与当时官方页面另行核实；证据不足时明确标记“未核实”。

## 安全边界

- 不编造 FDA/CE 认证、功效、销量、评价或品牌授权。
- 不上传商品资料、不联系平台、不改动真实 Listing；本技能只生成草稿与本地检查结果。
- 医疗、食品、儿童、化妆品、锂电池和捆绑商品须人工核对目标市场法律、平台分类及资料。
- 不承诺“保证上架”“保证排名”“保证不侵权”。

## 文件

- `bin/listing_check.py`：纯标准库、离线格式与措辞检查。
- `examples/sample_listing.md`：含故意加入的需复核措辞，不可直接发布。
- `references/official-policy.md`：官方政策来源、核对日期与不适用边界。
