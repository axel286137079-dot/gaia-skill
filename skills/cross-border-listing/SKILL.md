# 跨境 Listing 优化

把中文商品信息整理为**面向搜索的多语种 Listing 草稿**，并做基础合规提示。脚本不能保证排名、避免侵权或防止下架。

## 何时使用

- 用户要写亚马逊 / 独立站 / TikTok Shop 的 Listing
- 用户要生成标题、五点描述、Search Terms、多语种版本
- 用户要自查 Listing 会不会踩违禁词 / 超长 / 违规符号

## 工作流（四步）

### 1. 理解商品
- 输入：中文产品名 + 卖点 + 目标站点（默认美国站）。
- 提炼：核心卖点、目标人群、使用场景、差异化。

### 2. 生成标题（亚马逊 2026 新政）
- **Item name ≤75 字符（含空格）**：2026-07-27 起非 Media 类目统一执行；Media（图书/影音）仍 200。
- **公式**：`[品牌] + [核心产品词] + [关键规格] + [强区分属性]`，核心词前置（移动端仅完整展示前 50 字符）。
- 同一实词最多出现 2 次；禁止 emoji、重复标点（!!! / …）、HTML、官方禁用符号（! $ ? _ { } ^ ¬ ¦，品牌名内含时例外）。
- 标题放不下的材质/兼容/场景/卖点 → 写入 **Item Highlights**（≤125 字符、可搜索、随标题展示），勿堆回标题。
- 禁止：全大写、促销词、夸大词、竞品对比。标题不要写到正好 75，留 5~10 字符冗余。

### 3. Item Highlights + 五点描述
- 每点：卖点前置 + 场景化 + 量化（尺寸/材质/容量/适用人群）。
- 结构：`[卖点词] - [一句话说明 + 场景/数据]`，每点建议 ≤200~255 字符（移动端可读性），禁 emoji、保证性措辞、不可验证宣称。
- 五点被平台判定不合规时，亚马逊可对其执行 **AI 改写**——违规不只是不排名，内容可能被替换成你未写的版本。

### 4. Search Terms + 多语种
- Search Terms：埋长尾关键词 + 同义词 + 拼写变体（不重复标题已有关键词）。
- **按字节计上限**：美国/英国/欧盟 **249 bytes**、日本 500 bytes、印度 200 bytes；超出 1 字节即可能**静默取消该词索引**（不报错）。
- 商品描述（Standard Product Description）：**2000 字符、纯文本**（HTML 自 2021 起已移除）。
- 多语种：按目标站点翻译（英/德/日/西/法），保留关键词本地化。

### 4b. 图片与 A+ 内容（2026-07-27 新增要求）
- **含写实 AI 生成人物的商品图与 A+ 视频**，须在上传前于图片 **XMP `dc:subject`** 字段写入关键词 `contains-synthetic-performer`。
- 真人出镜、非写实形象、无人物图**免于此要求**。
- 主图须白底、产品占画面 85%；图片长边 500~10,000 px（建议 >1,000 px 以支持放大）。
- 使用 AI 生活场景图的品牌，应在内容流程中增加一步「资产标注复核」，漏标可能导致图片被处理。

### 4c. 捆绑与类目合规自查（2026-09-30 / 11-02 截止）
在生成文案前，先确认商品本身是否踩到 2026 下半年两项硬性合规线，避免「文案写好了、listing 先被压制」：

| 自查项 | 判定 | 动作 |
|---|---|---|
| 多件装/套装是否由**原厂或品牌方**包装？ | 自行拼装或第三方 prep 组装 → 不合规 | 9-30 前清货或移除；若品牌授权，走 Account Health 提交 LOA |
| 是否属礼品篮 / 相机套装 / 持 LOA？ | 属三类例外之一 | 可继续销售，保留凭证 |
| 是否发往 Amazon Business 客户的 FBM 订单？ | 是 → 看 BHDR | 查 Account Health → Program Eligibilities；达标线 90%（14 天滚动） |
| 是否属 11 个增强安全类目组？ | 是 → 需 $100 万责任险 | 11-02 前投保；注意按上架触发，与月销售额无关 |
| **主体是否注册在中国大陆？** | 是 → 11-02 起**新单只能走 AIA** | 走 卖家后台 → 设置 → 账户信息 → 业务信息 → 商业保险；第三方新单**一律拒收** |

> **中国大陆卖家专项（2026-11-02 起，最易踩坑）**：
> - **渠道锁定**：11-02 之后提交的**新保单**必须通过亚马逊保险加速器 **AIA**（Amazon 与 Marsh 合作运营，已接入太平洋保险、人保等机构）取得；**自行从第三方渠道购买的新单将被平台拒绝**。
> - **过渡窗口**：11-02 **之前**已提交并通过审核、且符合保额要求的第三方保单可**沿用至到期**；**到期后必须切 AIA 续保**。手里有合规第三方保单但还没上传的，务必赶在 11-02 前提交审核以锁定过渡期（审核需排队，别卡 10 月底）。
> - **硬性指标**（缺一即被驳回）：单次事故 ≥$100 万且累计 ≥$100 万；期内发生式（occurrence-based）；附加被保险人为「Amazon.com Services LLC and its affiliates and assignees」；**被保险人名称须与后台法律实体一字不差**；免赔额 ≤$10,000、无 sunset clause；承保公司需有全球理赔能力及 S&P A- / AM Best A- 以上评级。
> - **未合规后果**：逾期未提供有效保单，对应增强安全类目 listing **直接下架/停售**（不是先警告）——旺季前断链、排名与 Review 权重清零。
> - **时间提示**：AIA 出单 → 保险公司核保 → 亚马逊凭证审核均有周期，建议预留 **1~2 个月**。

> 提示：捆绑政策与增强安全类目清单都会继续扩充，**上架前先自查、别等平台通知**；一旦被压制或停用，恢复成本远高于提前处理。

### 5. 合规自查（发布前必做）
```bash
python3 bin/listing_check.py listing.md
# 输出：违禁词 + 标题长度(≤75)/符号/重复词 + Item Highlights(≤125)
#      + Search Terms 字节数 + 描述长度/HTML + 全大写 检查
# Media 类目（标题仍 200）：python3 bin/listing_check.py listing.md --title-max 200
```

> **2026 亚马逊政策速记**：
> ① **标题 200→75**（2026-07-27 非 Media），溢出信息由 Item Highlights（125）承接；品牌卖家对平台 AI 建议改写有 14 天复核窗口，主动先改可避免关键词/措辞失控。
> ② **AI 生成人物图须标注** `contains-synthetic-performer`（XMP dc:subject，2026-07-27 生效）。
> ③ **后端 Search Terms 按字节计**（249/500/200），超 1 字节静默失效。
> ④ **Featured Offer（Buy Box）** 2026-07 起取消独立卖家资格门槛，改为持续评估价格/时效/绩效——竞争加剧，勿为抢位牺牲毛利。
> ⑤ **Seller Fulfilled Prime 门槛提高**：标准尺寸 1 日达 40%、2 日达 75%（原 70%）、5 日达 90%，需周末发货且准时率约 93.5%。
> ⑥ **BSA 更新（2026-08-24 生效）**：禁止转让协议权利义务，或将其（含未来亚马逊拨款）作为质押/担保。
> ⑦ **捆绑销售政策全品类化（2026-09-30 生效）**：原仅限消耗品的「必须由原厂/品牌方包装」要求扩展到**几乎所有品类**。自行组装的 DIY 多件装、由第三方 prep 服务拼装的套装均属**不合规，listing 可能自 9-30 起被压制（suppressed）**。仅三类例外：gifting 浏览节点的礼品篮、camera 产品类型的相机套装、持有品牌方**授权函（LOA）**的套装。LOA 可在检测到违规后通过 Account Health 提交，但不阻止压制先发生——最稳的做法是**提前自查并清掉不合规 ASIN**。
> ⑧ **B2B 营业时段送达率 BHDR（2026-09-30 生效）**：卖家自配送（FBM）发往 Amazon Business 客户的订单，须满足**滚动 14 天内 ≥90%** 在客户营业时段送达。**FBA 完全豁免**。执行分两段：9-30 未达标先警告，**10-30 仍未改善则停用 B2B 的 FBM offer**（FBA 与普通零售 offer 不受影响）。捷径：**同时启用 Automated Handling Time + Shipping Settings Automation + Amazon Buy Shipping** 三者，只要按时发货即自动豁免。
> ⑨ **商业责任险（2026-11-02 生效）**：增强安全类目（**截至 2026-09-04 已扩至 11 个类目组**：儿童用品、消耗/摄入类、消防类、通用家用电器、家用医疗器械、锂电池、户外动力与取暖设备、个人安全防护、寝具、运输相关、水上与船舶安全）**按「上架即触发」而非按销售额触发**——月销不足 $10,000 也不豁免，须持 **$100 万**商业责任险；收到通知后 45 天内提交凭证，否则该类目 listing 可能被停用。小家电（空气炸锅/烤面包机/咖啡机/搅拌机）、床垫、轮胎、发电机/高压清洗机、助行器、头盔与攀岩装备、救生衣与泳池护栏等**常被误判为不受管制的品**都在范围内。亚马逊明确该清单**不完整且会继续扩充**。
> ⑩ **保险渠道收紧（2026-11-02 生效，中国大陆主体专属）**：**中国大陆注册卖家**自 11-02 起**新提交的保单必须经 Amazon Insurance Accelerator（AIA）获取**，第三方渠道新单平台**拒收**；11-02 前已提交并通过审核的合规第三方保单可用至到期，**续保同样须走 AIA**。原有「月销超 $10,000 则 30 天内投保」规则**继续有效**（本次是**叠加**两道新锁，不是替换）。未按期提供合规保单，高危类目 listing **直接下架**。
> ⑪ **美国站旺季附加费与超龄库存（2026-10-15 起）**：假日旺季配送附加费 **10-15 至 2027-01-14** 执行，覆盖 FBA、远程配送、多渠道配送与 Buy with Prime，按**仓库出库时间**判定，退货不退款；同时超龄库存附加费计费起点**降至 181 天**，超 456 天产生高额附加费——旺季前清理滞销库存。另：**美国站 MCF 同期加收旺季配送费**（小标准件约 $7.71、含锂电池再 +$0.11，偏远地区附加费可达订单费 100%），叠加原有 3.5% 燃油物流附加费，多渠道（Walmart/独立站/Shopify）须重算毛利。
> ⑫ **危险品新增问询（2026-10-26 起，美国站）**：在四类目组**新建或编辑** listing 时须回答新危险品问题——**制冷类**（冰箱/空调/冷柜，涉冷媒气体）、**悬挂减震类**（减震器/举升支撑，涉机械机构）、**书写工具类**（马克笔/书写笔，涉墨水性质）、**泳池与 SPA 水处理类**（涉化学成分与包装）。答案须基于**实际产品资料**（规格书/SDS/成分浓度/包装形态），不可按宽泛类目或标题推测；证据须对应被上架的**具体型号版本**，供应商同类型号声明不能直接替代。建议先建 ASIN 级清单+证据包再动 listing。⚠️ 亚马逊通知存在时间表述冲突（另一处提及 2026-08-31），以「10-26 + 新建或编辑触发」为可操作节点，并以目标站点实时流程复核。
> ⑬ **Handling Time 自动化（2026-10-20 起，英国站首批）**：卖家自配送 SKU 若滚动 30 天内**设置的处理时间比实际履约表现长 1 天及以上**，平台自动启用 **90 天**自动化处理时间并据此重设，SKU 全程保持可售可见。两条路径：配送设置中启用自动化处理时间（推荐），或 SKU 级手动设置并与实际表现对齐。建议先查 Handling time report 对账。
> ⑭ **Buy Shipping 支持 LTL 大件标（2026-10 起，美国站）**：厚重/大件订单可在 Buy Shipping 内购买 LTL 零担标，享亚马逊协议运价与**迟到配送保护**（此前自发货运费自理、且承运商致延误仍易计账户健康）。配套：大件**区域化配送定价**预计 2027 年初推出；本地承运商匹配与 Seller Flex 扩展至大件在规划中。**FBA 费用不受影响**。

## 合规红线

| 类别 | 典型违禁 | 风险 |
|---|---|---|
| 绝对化/夸大 | best、#1、100%、perfect、ultimate | 亚马逊禁，违规下架 |
| 健康疗效宣称 | cure、treat、heal、anti-cancer、FDA approved | FDA 严查，高危 |
| 促销/引流 | sale、discount、free shipping、官网链接 | 亚马逊禁 |
| 标题规范 | 超 75 字符（2026-07 起，非 Media）、全大写、emoji/重复标点/官方禁用符号、同词超 2 次 | 违反格式规范，可能被 AI 改写 |
| Item Highlights | 超 125 字符；承载夸大/不可验证宣称 | 违反 2026 新政 |
| 图片/视频资产 | 写实 AI 生成人物图未标 `contains-synthetic-performer`（XMP dc:subject） | 2026-07-27 起要求，漏标有被处理风险 |
| 后端搜索词 | 超字节上限（249/500/200 bytes） | 超 1 字节即静默取消该词索引 |
| 商品描述 | 超 2000 字符、含 HTML、含保证性措辞 | 字段规范，可能被 AI 改写 |
| 捆绑销售（2026-09-30 起全品类） | 非原厂/品牌方包装的自行组装多件装；无 LOA 授权 | listing 可能被压制（suppressed） |
| B2B 营业时段送达率（2026-09-30 起） | FBM 发往 Amazon Business 客户 <90%（14 天滚动） | 10-30 未改善则停用 B2B FBM offer（FBA 豁免） |
| 危险品问询（2026-10-26 起，美国站） | 制冷/悬挂减震/书写工具/泳池 SPA 四类目组新建或编辑时未按实际资料回答（凭类目或标题推测） | 分类型错误可能导致上架延迟、发货方式受限或不必要处置费 |
| 处理时间（2026-10-20 起，英国站首批） | 卖家自配送 SKU 设置处理时间比实际履约长 ≥1 天（30 天滚动） | 平台自动启用 90 天自动化处理时间 |
| 大件物流（2026-10 起，美国站） | 自发货大件未走 Buy Shipping LTL，延误仍计账户健康 | 改用 LTL 可获迟到配送保护；2027 初区域化定价 |
| 商业责任险（2026-11-02 起） | 属 11 个类目组却无 $100 万商业责任险 | 45 天内未提交凭证，类目 listing 可能停用 |
| 保险渠道（2026-11-02 起，中国大陆主体） | 新单未走 AIA、走第三方渠道 | 平台直接拒收 → 逾期则高危类目 listing 下架 |

## 边界与红线

- 不生成虚假功效、伪造认证（FDA/CE 等）、侵权品牌词的描述。
- 涉及医疗器械、保健品、化妆品，务必核实目标站点合规要求（各国法规不同）。
- 不承诺「保证上架 / 保证排名」，只做「优化 + 合规自查」。
