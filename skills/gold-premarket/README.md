# 黄金盘前分析（gold-premarket）

面向**黄金买家**的每日盘前简报工具：一键拉取实时行情 + 技术指标 + 宏观快讯，输出「配置型」研判（看清今天该关注什么、处于什么位置、有什么风险），**不喊单、不荐股、不做高频信号**。

## 特性

- **零依赖**：纯 Python 标准库，无需安装任何第三方包，无需 API key。
- **三源直连**：新浪财经（现货行情 + 日 K）+ 金十数据（快讯流），全部免费、国内可直连。
- **分工清晰**：脚本负责「数据与指标」，Agent 负责「宏观研判与决策建议」。
- **配置型定位**：只给「买入/观望/暂缓」三档 + 关键点位，规避国内喊单/荐金合规风险。

## 安装

```bash
# 复制到技能目录
cp -r gold-premarket ~/.workbuddy/skills/
```

## 快速开始

```bash
# 1. 自检数据源连通性
python3 bin/gold_premarket.py test

# 2. 一键生成完整盘前简报
python3 bin/gold_premarket.py report
```

## 命令一览

| 命令 | 说明 |
|---|---|
| `quote` | 实时行情：伦敦金 / 伦敦银 / 美元指数（现价、涨跌幅、日内高低） |
| `kline [N]` | 近 N 日 K 线（默认 120）+ 技术指标（MA/RSI/ATR/布林带/Donchian） |
| `news [M]` | 金十快讯（黄金相关，默认 40 条） |
| `report` | 整合以上，输出六段式盘前简报 |
| `test` | 自检三源连通性 |

## 简报结构（六段）

1. **今日行情**：伦敦金 / 白银 / 美元指数现价与涨跌
2. **技术位置**：均线排列、RSI、ATR、布林带、Donchian、支撑阻力
3. **宏观驱动**：金十快讯流（美联储/地缘/通胀/央行）
4. **时段与季节性**：当前时段活跃度 + 月度季节性
5. **持仓决策**：🟢 买入 / 🟡 观望 / 🔴 暂缓（Agent 补全）
6. **风险提示**：事件日历 + 波动率 + 生存第一红线

## 数据源

| 源 | 内容 | 成本 |
|---|---|---|

| 金十数据 `flash_newest.js` | 财经快讯流 | 免费、无 key |
