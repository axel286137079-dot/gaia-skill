# 黄金盘前分析（Gold Premarket）

面向**黄金买家**的每日盘前简报工具：一键拉取实时行情 + 技术指标 + 宏观快讯，输出「配置型」研判（帮用户看清今天该关注什么、处于什么位置、有什么风险），**不做喊单、不做高频信号、不荐股**。

## 何时使用本 skill

出现以下任一意图即启用：

| 用户意图 | 典型说法 | 流程 |
|---|---|---|
| 看今日金价与走势 | 黄金现在多少钱 / 今天金价怎么样 | 流程 A：数据简报 |
| 判断该不该买 | 现在黄金能买吗 / 高不高 | 流程 B：决策研判 |
| 盘前/晨间快速过一遍 | 来个黄金盘前分析 / 晨报 | 流程 A+B 完整版 |
| 只要技术位/支撑阻力 | 黄金支撑阻力在哪 | 流程 A（取技术位置段） |

**一句话原则**：脚本负责抓取与计算，Agent 负责核验来源、说明不确定性并组织研究结论；不得把启发式结论包装成确定性建议。

## 核心资产

| 文件 | 作用 |
|---|---|
| `bin/gold_premarket.py` | 数据引擎（纯标准库，无第三方依赖），抓行情/日K/快讯并算指标 |
| `examples/sample_report.md` | 完整简报示例，可作排版参考 |

## 数据引擎用法

```bash
python3 bin/gold_premarket.py quote        # 实时行情：伦敦金/白银/美元指数
python3 bin/gold_premarket.py kline [N]    # 近 N 日 K 线 + 技术指标（默认 120）
python3 bin/gold_premarket.py news [M]     # 金十快讯（黄金相关，默认 40 条）
python3 bin/gold_premarket.py report       # 一键生成完整盘前简报
python3 bin/gold_premarket.py test         # 自检三源连通性
```

数据源（均免费、国内直连、无需 key）：
- 新浪财经现货行情：`hf_XAU` 伦敦金 / `DINIW` 美元指数 / `hf_XAG` 伦敦银
- 新浪财经日 K：`GlobalFuturesService.getGlobalFuturesDailyKLine`（XAU，2006 至今）
- 金十数据快讯流：`jin10.com/flash_newest.js`

## 工作流

### 流程 A：数据简报（脚本自动，Agent 只需解读）

1. 运行 `python3 bin/gold_premarket.py report`，得到六段简报骨架。
2. Agent 用平实语言解读关键数字，补充「这意味着什么」：
   - 涨跌幅是否异常（单日 >1% 属于大波动，>2% 属于事件驱动）
   - 均线排列与价格位置的背离（如多头排列但价格跌破 MA20 = 短期回调 vs 中期趋势的矛盾）
   - RSI 是否进入超买/超卖区
   - 快讯里是否有重磅事件（美联储官员讲话、地缘冲突、央行购金）

### 流程 B：决策研判（Agent 负责，需补充 web 搜索）

脚本不输出最终买卖建议——因为宏观定性（美联储政策路径、地缘走向、美元趋势）需要**实时搜索**补充，无法稳定脚本化。Agent 按下面顺序补全：

1. **搜索宏观面**（Step 1~3 可并行）：
   - 美联储：最新利率决议 / 官员讲话 / 下次 FOMC 时间与市场定价
   - 美元与实际利率：DXY 走势、10Y 美债收益率、10Y TIPS（实际利率）
   - 地缘：当前热点（中东/俄乌/台海等）与避险情绪
2. **逐项说明驱动因素**：实际利率、美元、地缘、通胀预期、央行政策、增长、市场情绪与实物供需。若无可验证模型，不给这些因素伪精确权重。
3. **给出情景结论**（偏强 / 中性 / 偏弱），明确证据、反例和失效条件。

### 输出模板（简报最终形态）

```
# 黄金盘前分析简报（YYYY-MM-DD）

## 一、今日行情
[表格：伦敦金/白银/美元指数 现价、涨跌幅、日内高低]

## 二、技术位置
[均线排列、RSI、ATR、布林带、Donchian、支撑阻力 —— 脚本已算好，Agent 解读]

## 三、宏观驱动
[脚本快讯 + Agent 搜索补充的定性研判]

## 四、时段与季节性
[当前时段活跃度 + 月度季节性]

## 五、情景研判
偏强 / 中性 / 偏弱（附 2-3 条证据、反例和关键观察位）

## 六、风险提示
[事件日历 + 波动率 + 生存第一红线]
```

## 判断标准（内部逻辑，不输出本节标题）

### 偏强情景（满足多数）
- 美联储降息预期增强 / 已进降息周期
- 美元指数走弱（<100 区间）
- 地缘风险上升，避险需求旺
- 实际利率偏低或下行
- 金价位于支撑位附近，技术面有支撑

### 中性情景（信号混杂）
- 多空因素并存，方向不明
- 价格高位震荡，突破方向未定
- 短期有回调风险，但中长期逻辑未破坏
- 等待重磅数据（非农/CPI/FOMC）

### 偏弱情景（满足多数）
- 美联储鹰派信号 / 加息预期升温
- 美元强势（>104）
- 金价短期暴涨（1 个月 >8%）技术超买
- 风险偏好回升，资金撤离黄金
- 实际利率快速上行

## 红线（必须遵守）

1. **不构成投资建议**：简报末尾必须带风险提示，措辞「仅供参考，不构成投资建议」。
2. **研究型不喊单**：只给情景判断和关键观察位，**不给出具体下单指令、仓位指令，不承诺收益，不推荐交易平台**。
3. **数据滞后声明**：行情可能有 15-60 秒延迟，成交以实际行情为准。
4. **风险说明**：说明波动、流动性、数据延迟和杠杆风险；不替用户设定个性化仓位或止损。
5. **不捏造数据**：技术位、涨跌幅、快讯必须来自脚本真实抓取；宏观定性若靠搜索，需标注信息来源与时间。
6. **国内合规**：面向国内散户时，避免「喊单」「带单」「跟单」表述，规避荐股/荐金合规风险。

## 最佳实践

1. **先跑脚本再说话**：所有客观数字一律取自脚本输出，不要凭记忆报金价。
2. **周期搭配**：短期（1-4 周）看技术位 + 事件日历，中期（1-3 月）看趋势 + 利率，长期看宏观大趋势（央行购金/去美元化）。
3. **事件日历联动**：非农/CPI/FOMC 前后 4 小时波动放大，简报里提醒谨慎。
4. **背离要提醒**：技术面与宏观面打架时（如技术多头但美联储鹰派），明确点出矛盾，倾向保守。
