# 中文深度研究 · 情报调研（中文信源版）

输入一个课题，产出**带出处、带可信度分级、可溯源**的中文深度研究报告——不是泛泛而谈，而是「结论可信、证据可查、分歧说清」。

## 一句话定位

本 skill 聚焦**中文信源的多源检索 + 交叉验证 + 引用审计**，用四级信源分级和反幻觉检查辅助产出可复核的中文报告。检索和引用本身仍由 agent 或用户完成。

## 为什么值得做

- AI 深度研究是当下最热的 agent 能力，但「会查英文」≠「会查中文」——公众号/知乎/天眼查/巨潮资讯/裁判文书/政策库这些中文一手信源，海外工具基本覆盖不到。
- 深度报告最大的翻车点是**幻觉**（编数据、编出处、拿旧数据当现状）；本 skill 用「信源分级 + 交叉验证 + 反幻觉审计」三道闸把可信度拉起来。
- 目标用户广：分析师、投研、咨询、自媒体、学生、尽调团队。

## 核心方法论

| 环节 | 做法 |
|---|---|
| 信源分级 | 官方/学术=一级，权威媒体/垂直平台=二级，行业自媒体=三级，匿名论坛=四级 |
| 交叉验证 | 关键事实 ≥2 独立信源，数字必须可溯源，冲突如实标注 |
| 反幻觉 | 不编造、区分事实与观点、不确定就标「待核实」、引用可追溯 |
| 报告结构 | 结论先行 → 分章节 → 数据证据 → 分歧 → 未证实项 → 信源清单 |

## 快速开始

```bash
# 报告写完后，做信源可信度审计 + 反幻觉检查
python3 bin/source_audit.py 报告.md

# 示例：对示范报告跑审计
python3 bin/source_audit.py examples/sample_report.md
```

## 目录结构

```
deep-research-cn/
├── SKILL.md                 # 路由逻辑 + 信源四级分级 + 交叉验证 + 反幻觉红线
├── README.md                # 本文件
├── bin/source_audit.py      # 信源可信度审计脚本（纯标准库，离线可跑）
└── examples/
    └── sample_report.md     # 示范报告（含 [来源N] 标注 + 信源清单）
```

## 合规红线

- 不编造数据、引文、URL；查不到就说查不到。
- 不替代专业意见（涉及投资/法律/医疗结论须提示「非专业意见，仅供参考」）。
- 涉及监管、主权、政策事实，一律以官方发布为准。
