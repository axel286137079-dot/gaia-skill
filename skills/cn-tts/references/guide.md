# 输入、引擎与交付边界

## 输入与参数

单条 `python3 bin/tts.py [synth] "文本" [--file text.txt]`。指定 file 时文件文本优先，UTF-8 读取，去除首尾空白后必须非空。缺文件、目录或解码失败受控非零。不自动读其他客户文件。

`--voice` 默认为晓晓，支持14个昵称及完整 edge 名（list-voices列出）；say可直接传本机音色名，预置婷婷/Tingting、美佳/Meijia、善怡/Sinji。`--rate +10%`、`--pitch +10Hz`、`--volume +20%` 原样交给 edge；say 不承诺应用这三个调节项。默认+0%/+0Hz/+0%。不新增任意参数配额/自定商用音色白名单。say实际.wav目标显式传`--file-format=WAVE --data-format=LEI16`，不附加固定rate；AIFF和原MP3改AIFF不添加这些格式参数。

`--timeout-seconds` 是每次引擎进程调用的上限，必须为1至3600的整数，默认300。非法值在查找或执行引擎前拒绝。auto模式中edge与say回退各自获得完整上限；本工具不自动重试。超时异常不回显命令或正文。

`batch manifest.json --out-dir output/ [--engine auto|edge-tts|say]` 的根为数组，每项为对象，text非空字符串；voice/rate/pitch/volume若提供须字符串。out缺省/null/空字符串采用原顺序0001.mp3等；其他out须字符串。额外键忽略，空数组合法0/0。完整结构错误在mkdir/引擎执行前拒绝，不输出坏值。

相对out基于out-dir，单条默认out.mp3基于当前cwd。允许绝对out、../和父目录别名。目标父目录应已存在（batch会创建out-dir，不自动创建任意逐项嵌套父目录）。引擎依赖由用户自行配置；不安装或验证在线服务当前版本/授权。edge文本通过参数传给用户授权的联网工具；say通过标准输入交给本机工具。日志捕获并摘要化，不等于正文在本地进程参数或已授权网络传输中不可见。

引擎版本：edge-tts 需 ≥7.3.1。微软 2026-10-12 将 Edge 朗读接口的 Sec-MS-GEC 时间令牌轮换为第二代，7.2 系列及更早版本（含 7.2.8）自此全部 403；7.3.0 为首个支持 v2 令牌的版本，7.3.1 修复其按系统语言解析服务端 Date 头导致的时钟校准失败。执行前探测到低版本时告警但不阻断，最终以实际调用结果为准；捕获到 403 时给出「升级 / 校验时钟 / 复测出口 IP」三级指引，不提供令牌伪造方案。版本数值仅供升级判断，不构成线上可用性承诺。

## 成果判定与部分结果

每一次引擎尝试在同一输出父目录新建私有暂存目录；auto前后两次尝试不共用产物。只接受当前尝试预期路径的非空普通非链接文件，验证lstat/fstat身份。exit0但无文件/空文件不成功；auto仍可say回退。超时残片只在身份仍匹配时清理，不发布、不覆盖旧输出；不明对象保留并诚实报错。该检查不鉴定音频格式、可解码性、音质或第三方服务真实性，可信引擎本身不是本工具隔离的恶意二进制沙箱。

重复请求目标/强制say的确定性后缀碰撞提前拒绝，auto潜在但不实际碰撞的组合允许；运行中实际碰撞按该条失败，前成果保留。批次结构正确后的引擎/交付失败继续后项，最终非零摘要。不是全批事务，不回滚已提交。清理失败即使文件已提交也明确报“已提交但后续失败”，不宣称完全成功。

## 文件系统保护与范围

保护本次--file/manifest及本包既有12个公开材料目录项，不禁止在技能cwd新建/顺序更新音频。不同目录项旧硬链接采用新inode替换，不截断原输入/外部别名。最终有效/悬空软链接、目录、FIFO等特殊叶拒绝。缺原生目录句柄/安全操作能力受控拒绝；仅实际测试macOS Python3.9/3.14，未宣称Windows实测。

父目录resolve后以目录句柄绑定和复验；固定长度目标摘要锁防协作同目标并发，未知锁保留、不自动抢占、不无限等待。新叶通过atomic link无覆盖；旧普通叶保初始stamp，提交前复验后replace更新。只清理可观察身份匹配的本人暂存和锁。可观察目标/目录/暂存/锁变化受控失败；不删除不明外来对象。

锁是协作机制。旧叶stat→replace、暂存身份检查→link/replace、清理身份检查→unlink均不是原子inode-CAS；同账号不协作最后瞬时交换对象/祖先目录仍有窗口，不承诺任意目录/恶意进程沙箱、断电恢复或全部竞态防御。新叶atomic no-clobber只说明目标目录项不会被该操作覆盖，不能推广为全部身份保证。
