# 中文语音合成 0.1.8

从单条文字、UTF-8 文本文件或 JSON 批次交付语音文件的标准库编排工具。使用方式、授权提醒见 [SKILL.md](SKILL.md)，字段和交付限制见 [guide](references/guide.md)。

```bash
python3 bin/tts.py "你好，这是合成示例。" --engine say --voice 婷婷 --out example.wav
python3 bin/tts.py --file text.txt --engine say
python3 bin/tts.py batch examples/manifest.json --engine say --out-dir output/
python3 bin/tts.py list-voices
```

`--timeout-seconds` 控制每次引擎调用的最长等待，默认300秒，允许1至3600秒。超时不覆盖已有输出；批量任务会继续后项并最终返回非零。

默认 auto 的 edge-tts 需要网络，say 为 macOS 本地工具；此工具不自动安装依赖。14种预置中文音色不等于当前第三方服务必然可用。预置完整名/昵称可查询 list-voices，macOS 另支持直接本地音色名。

0.1.7 恢复并延续0.1.5已审查的安全交付基线，新增有界等待、超时后暂存清理、旧输出保护和批量继续。每次引擎尝试使用独立暂存，避免失败或超时残片冒充成果。结构错误在引擎执行前拒绝；运行错误逐项继续并诚实报告。

截至2026-10-21，PyPI公开的 edge-tts 最新版本为7.3.1；在线接口与第三方包会变化，使用者应从项目官方发布页核对当前版本。工具不自动安装、升级、重试或承诺线上可用性。

**0.1.8 版本红线**：微软于 2026-10-12 轮换 Edge 朗读接口的 `Sec-MS-GEC` 时间令牌至第二代，**整个 7.2 系列及更早版本（含 7.2.8）全部 403**。可用版本为 7.3.0（首个支持 v2 令牌）与 **7.3.1（修 7.3.0 的时钟校准缺陷，推荐）**。因此本技能要求 `edge-tts>=7.3.1`，`bin/tts.py` 会在合成前探测版本，低版本给出定向告警；捕获到 403 时输出三级排障指引，并明确不建议自研伪造令牌。安装与升级一律写带版本下限的命令。

```bash
pip install --upgrade 'edge-tts>=7.3.1'
```

14 种预置中文音色在同期核对中仍全部在线（`list-voices` 共 322 个音色），音色名无需变更。

WAV路径显式指定WAVE容器/LEI16 PCM，不强制采样率；AIFF与MP3改AIFF行为不变。实施者测试仅使用严格检查参数的本地假引擎；主审另有本机say WAV/AIFF文件对照，无播放，不把假样例冒充真实可播放声音，也不提供音质、在线可用性或第三方许可背书。

普通已有输出允许安全替换，最终叶链接/特殊文件拒绝；并非任意路径沙箱、恶意引擎沙箱、inode-CAS 或跨文件事务。本代码 MIT；实际引擎、音色、输入与输出权利需使用者另行确认。
