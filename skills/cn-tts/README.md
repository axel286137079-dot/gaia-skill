# 中文语音合成

把中文文本转成**自然的语音音频**，14 种音色 + 语速/音调/音量调节 + 批量合成，免 API key。

## 一句话定位

短视频 / 有声书 / 课程配音需求巨大，但「好用、低成本、能接进 agent」的中文 TTS skill 稀缺；本 skill 用 edge-tts（免费高质量 14 音色）+ macOS say（本地离线）双引擎封装，一条命令搞定中文配音。

## 为什么值得做

- 中文是多音字 + 多声调语言，通用英文 TTS 效果差，中文音色（含粤语/台腔/东北/陕西口音）是刚需。
- 大厂 TTS 都要 API key + 按量计费；edge-tts 免费且音质接近大厂，是性价比最优解。
- 只做「合成」不做「声纹克隆」，合规风险低，适合内容生产链路长期复用。

## 快速开始

```bash
# 单条合成
python3 bin/tts.py "你好，欢迎来到强大心态训练。" --voice 晓晓 --out 音频.mp3

# 从文件合成
python3 bin/tts.py --file 文本.txt --voice 云希 --rate +10%

# 批量合成
python3 bin/tts.py batch examples/manifest.json --out-dir out/

# 查看全部音色
python3 bin/tts.py list-voices
```

## 音色速查（14 种）

普通话：晓晓(女温暖)/晓伊(女活泼)/云健(男激情)/云希(男阳光)/云夏(男可爱)/云扬(男专业)
方言口音：晓北(东北)/晓妮(陕西)
粤语：曉佳/曉曼/雲龍
台腔：曉臻/曉雨/雲哲

## ⚠️ 版本红线与 403 排障

接口验证已进入**第二代**，两代互不兼容（请求头 `Sec-MS-GEC-Version` 与 token 结构都变了，只改前缀不换算法照样 403）：

| 版本 | 状态 |
|---|---|
| 6.1 全系列 | ❌ 403 |
| 7.2.1 ~ 7.2.8 | ⚠️ **2026-10 起集体 403**（7.2.8 是上一轮红线，现已失效） |
| **7.3.0 / 7.3.1** | ✅ 唯一可用（2026-10-13 加入 v2 token；7.3.1 修 `Date` 头按语言解析导致的校准失败） |

```bash
pip install -U "edge-tts>=7.3.1"
python3 -c "import edge_tts; print(edge_tts.__version__)"   # 必须 ≥7.3.1
```

若版本已对仍 403：① 先确认 `edge_tts.__version__` 真的生效（多环境常装到旧版）；② 检查代理是否改写请求头，直连试一次；③ 核对系统时钟（7.3.1 已修语言相关的 `Date` 解析问题），必要时 `--proxy` 换出口；④ 去 releases 页看微软是否又换了一代。`NoAudioReceived` 属服务端偶发，需自行包重试循环。

> 该接口是逆向端点，**2024-10 与 2026-10 各发生过一次全版本失效**；批量任务先跑一条最小样本验证当前版本，再全量。

## 边界与红线

- **授权性质**：edge-tts 调用的是 Edge 浏览器「大声朗读」接口，**微软未授予商用许可**；浏览器朗读可用 ≠ 获得商用输出权。商用/高可用请用 Azure Speech S0 付费层（**免费层 F0 产物不带商用使用权**）或本地引擎 Kokoro-82M（Apache-2.0）/ Piper（MIT）。
- 该接口为内部端点，**无 SLA**，微软可随时变更验证策略使旧版本集体失效。
- 只做合成，**不做声纹克隆**（涉及声音权/肖像权）。
- 不得用于诈骗、冒充他人、传播虚假信息。
