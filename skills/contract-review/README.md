# 合同审查助手

上传合同 → 输出**风险点分级 + 关键条款白话解释 + 修改建议**（明确「非法律意见」）。

## 一句话定位

法律类是全球市场「最稳定可售卖」的 skill 品类，但中文法律语境 + 大陆法条/监管的 skill 稀缺；本 skill 用「规则化风险扫描 + LLM 条款解读」两步，把合同风险点先扫出来、再白话讲清。

## 为什么值得做

- 中小企业主、自由职业者签合同前最缺「有人先帮我扫一遍风险」，但请律师有门槛。
- 高风险条款（单方解除、无限责任、免责、自动续约）有固定表述规律，可以规则化预扫。
- 本工具不替代律师，但能把「该注意什么」提前讲清，降低踩坑概率。

## 快速开始

```bash
# 风险扫描（本地离线）
python3 bin/contract_scan.py 合同.txt

# 带上下文 / JSON
python3 bin/contract_scan.py 合同.txt --context 30
python3 bin/contract_scan.py 合同.txt --json
```

## 示例

```bash
python3 bin/contract_scan.py examples/sample_contract.txt
```

## 覆盖的风险清单

| 等级 | 类别 | 典型表述 |
|---|---|---|
| 高 | 单方解除 / 无限责任 / 免责 / 自动续约 / 独占排他 / 管辖 | 任意解除、连带责任、概不负责、自动续约、权利归甲方 |
| 中 | 模糊表述 / 保证金 / 账期 | 合理期限、及时、尽力、定金、预付款 |
| 低 | 格式提示 | 最终解释权、以合同为准 |

## 目录结构

```
contract-review/
├── SKILL.md                   # 路由逻辑 + 风险清单 + 合规红线
├── README.md                  # 本文件
├── bin/contract_scan.py       # 高风险条款扫描（纯标准库，离线可跑）
└── examples/sample_contract.txt  # 示例（含演示用的风险条款）
```

## 边界与红线

- **不构成法律意见，不替代律师**——重大合同务必咨询执业律师。
- 不臆造法条，不确定就只给风险提示。
- 不替用户做决定，是否签署由用户判断。
