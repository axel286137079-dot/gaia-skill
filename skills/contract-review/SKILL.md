# 合同审查助手

上传合同 → 输出**风险点分级 + 关键条款白话解释 + 修改建议**。

> **⚠️ 重要声明：本工具仅做风险提示与法律科普，不构成法律意见，不替代律师。涉及金额大、权利义务复杂的合同，务必咨询执业律师。**

## 何时使用

- 用户要审合同 / 看合同风险点 / 解读某条款
- 用户签劳动合同、租房合同、买卖合同、合作协议、保密协议前想先扫一遍
- 用户要「白话解释」某句法言法语

## 工作流（三步）

### 1. 风险扫描（规则化，本地离线）
```bash
python3 bin/contract_scan.py 合同.txt
# 输出：命中的高风险条款 + 等级 + 位置 + 建议
```

### 2. 条款解读（LLM）
- 把命中的高风险条款用**白话**解释：这条约定了什么、对谁不利、最坏后果是什么。
- 逐条给「修改建议」：删掉 / 改成对等 / 加限制条件。

### 3. 分级汇总
- **高风险**：可能让你承担超额责任、失去主动权 → 必须谈，谈不拢不签。
- **中风险**：模糊表述、单向倾斜 → 建议修改。
- **低风险**：格式/提示类 → 知悉即可。

## 高风险条款清单（扫描器内置）

| 风险 | 典型表述 | 为什么危险 |
|---|---|---|
| 单方解除权 | 无条件解除 / 随时解除 / 任意解除 | 对方可随时终止，你无主动权 |
| 无限/连带责任 | 连带责任 / 无限责任 / 不设上限 | 责任无上限，风险敞口大 |
| 免责条款 | 概不负责 / 不承担任何责任 | 对方免责，你全扛 |
| 自动续约 | 到期自动续约 / 自动顺延 | 到期不主动停就一直续 |
| 违约金过高 | 违约金超过 XX% | 罚则过重 |
| 独占/排他 | 独家 / 排他 / 权利归甲方 | 你被锁死 |
| 模糊表述 | 合理 / 及时 / 尽力 / 尽快 | 不可量化，纠纷时说不清 |

## 边界与红线（必须遵守）

- **不构成法律意见**：每次输出必须带「非法律意见」声明。
- **不替代律师**：重大合同、涉及大额资金或核心权益的，必须建议咨询执业律师。
- **不臆造法条**：引用法条（《民法典》《劳动合同法》等）必须准确，不确定就只给风险提示、不硬套条文。
- **不替用户做决定**：只列风险和建议，是否签署由用户判断。
