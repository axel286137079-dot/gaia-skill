# 小红书内容工厂

把小红书内容生产串成一条**可被 agent 调用**的流水线：选题 → 文案 → 封面 → 排版 → 敏感词自查 → 发布。

## 一句话定位

网页工具（创客贴/稿定）一堆，但「skill 形态、全流程、能自动发布」的少；本 skill 补上内容生产侧的自动化闭环，发布环节委托已有的 `xiaohongshu` skill 执行。

## 为什么值得做

- 小红书是当下内容变现主战场，但「会写」和「会写不被限流」是两码事。
- 广告法极限词（最/第一/顶级）、医疗绝对化、引流导流是限流封号三大杀手，多数创作者靠感觉自查，遗漏率高。
- 本 skill 内置违禁词自查，交稿前先跑一遍，把「踩雷」挡在发布之前。

## 快速开始

### 敏感词自查（核心工具）
```bash
python3 bin/xhs_sensitive_check.py 笔记.md
# 输出：命中的违禁词 + 类别 + 位置 + 替换建议

python3 bin/xhs_sensitive_check.py 笔记.md --json   # 便于 agent 消费
```

### 示例
```bash
python3 bin/xhs_sensitive_check.py examples/sample_note.md
```

## 覆盖的五类违禁词

| 类别 | 典型词 | 风险 |
|---|---|---|
| 广告法极限词 | 最好/第一/顶级/国家级/唯一/100% | 违规+限流 |
| 医疗绝对化 | 根治/治愈/永不复发/无副作用 | 医疗类严查 |
| 金融诱导 | 稳赚/保本/零风险/月入过万 | 封号高危 |
| 引流导流 | 加微信/私我/淘宝/二维码 | 平台禁导流 |
| 教培夸大 | 包过/保过/押题/命中率100% | 违规 |

## 目录结构

```
xhs-content/
├── SKILL.md                    # 路由逻辑 + 五步工作流 + 标题公式 + 红线
├── README.md                   # 本文件
├── bin/xhs_sensitive_check.py  # 违禁词自查（纯标准库，离线可跑）
└── examples/sample_note.md     # 示例笔记（含演示用的违禁词）
```

## 边界与红线

- 不代写医疗/金融/教育的绝对化承诺，涉及这些领域须标「非专业建议」。
- 不生成涉政、色情、低俗内容。
- 违禁词库是「提醒」非「免责」，发布前仍建议人工复核平台最新规则。
