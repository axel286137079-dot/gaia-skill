# 小红书内容工厂

把小红书内容生产整理成：**选题 → 文案 → 封面文案 → 排版 → 敏感词提示 → 人工确认**。发布是独立的外部操作。

## 何时使用

- 用户要写小红书笔记 / 种草文案 / 爆款标题 / 封面文案
- 用户要批量起号、做品牌矩阵号
- 用户要「自查文案会不会限流/踩违禁词」
- 用户准备发布内容时，先完成草稿和风险提示；外部发布需另行明确授权

## 工作流（五步）

### 1. 选题
- 蹭「低竞争 + 高搜索」关键词：用站内搜索联想词 + 低粉爆款笔记反推。
- 选题四问：给谁看？痛点是什么？我能给什么独特解法？为什么是现在？

### 2. 文案
- **标题公式**（四选一）：①数字+结果「3 步戒掉内耗」②反常识「越努力越穷的 5 个习惯」③身份+痛点「给 25 岁还在内耗的你」④提问式「为什么你总在深夜焦虑」。
- **正文结构**：钩子（前 2 行定生死）→ 痛点共鸣 → 干货/观点 → 互动引导 → 话题标签。
- **口语化改写**：短句、多用「你」、少用书面语和 AI 腔（比如「首先/其次/综上所述」一律删）。

### 3. 封面
- 竖版 3:4（1242×1656），大字标题 + 高对比色块，前 3 个字决定点击率（差 30~50%）。
- 封面文字也走敏感词自查（见第 5 步）。

### 4. 排版
- 正文分段 + emoji 分点 + 适当留白，避免一整坨；关键词埋进前 100 字。

### 5. 敏感词自查（发布前必做）
```bash
python3 bin/xhs_sensitive_check.py 笔记.md
# 输出：命中的违禁词 + 类别 + 位置 + 替换建议
```
覆盖五类：广告法极限词 / 医疗绝对化 / 金融投资诱导 / 引流导流 / 教育培训夸大。

### 6. 发布前交接
- 汇总文案、封面、标签和风险提示，等待用户确认；本 skill 本身不执行发布。

## 敏感词红线（五类）

| 类别 | 典型违禁词 | 风险 |
|---|---|---|
| 广告法极限词 | 最、第一、顶级、国家级、唯一、100%、永久、史无前例 | 违规+限流 |
| 医疗绝对化 | 根治、治愈、永不复发、无副作用、包治百病 | 医疗类严查 |
| 金融诱导 | 稳赚、保本、零风险、月入过万、躺着赚钱 | 封号高危 |
| 引流导流 | 加微信、加V、私我、淘宝、拼多多、二维码 | 平台禁导流 |
| 教培夸大 | 包过、保过、押题、命中率100%、必过 | 违规 |

## 边界与红线

- 不代写「医疗/金融/教育」的绝对化承诺，涉及这些领域必须标注「非专业建议」。
- 不生成涉政、色情、低俗内容。
- 敏感词库是「提示」不是「免责」，发布前仍建议人工复核平台最新规则。
