# 小红书内容工厂

把小红书内容生产整理成：**选题 → 文案 → 封面文案 → 排版 → 敏感词提示 → 人工确认**。发布是独立的外部操作。

## 何时使用

- 用户要写小红书笔记 / 种草文案 / 爆款标题 / 封面文案
- 用户要批量起号、做品牌矩阵号
- 用户要「自查文案会不会限流/踩违禁词」
- 用户准备发布内容时，先完成草稿和风险提示；外部发布需另行明确授权

## 工作流（五步）

### 1. 选题
- 蹭「低竞争 + 高搜索」关键词：用站内搜索联想词 + 低粉爆款笔记反推。
- 选题四问：给谁看？痛点是什么？我能给什么独特解法？为什么是现在？

### 2. 文案
- **标题公式**（四选一）：①数字+结果「3 步戒掉内耗」②反常识「越努力越穷的 5 个习惯」③身份+痛点「给 25 岁还在内耗的你」④提问式「为什么你总在深夜焦虑」。
- **正文结构**：钩子（前 2 行定生死）→ 痛点共鸣 → 干货/观点 → 互动引导 → 话题标签。
- **口语化改写**：短句、多用「你」、少用书面语和 AI 腔（比如「首先/其次/综上所述」一律删）。

### 3. 封面
- 竖版 3:4（1242×1656），大字标题 + 高对比色块，前 3 个字决定点击率（差 30~50%）。
- 封面文字也走敏感词自查（见第 5 步）。

### 4. 排版
- 正文分段 + emoji 分点 + 适当留白，避免一整坨；关键词埋进前 100 字。

### 5. 敏感词自查（发布前必做）
```bash
python3 bin/xhs_sensitive_check.py 笔记.md
# 输出：命中的违禁词 + 类别 + 位置 + 替换建议 + 2026 平台审核提示
```
覆盖九类：广告法极限词 / 医疗绝对化 / 金融投资诱导 / 引流导流（含谐音变体）/ 教育培训夸大 / 网络热词极限宣传(2026) / 竞品拉踩(2026) / 美妆护肤红线(2026) / 焦虑营销与虚假福利(2026)。

> **2026 审核变化（务必内化）**：① AI 生成文案/图片必须标注「AI 辅助创作」；② 谐音、拼音、符号隔断、拆字等规避违禁词的手段已被识别，直接合规表达；③ 带货文案中「天花板/封神/yyds/绝绝子」等网络热词按极限宣传判定；④ 贬低竞品零容忍；⑤ 化妆品禁标「无激素/0刺激/食品级/医用级」等。

### 6. AI 标注与发布前交接
- **AI 生成内容（本 skill 产出即属此类）须向用户提示：发布时勾选「AI 辅助创作」标注**，未标注可能限流降权。
- 汇总文案、封面、标签和风险提示，等待用户确认；本 skill 本身不执行发布。

## 敏感词红线（九类）

| 类别 | 典型违禁词 | 风险 |
|---|---|---|
| 广告法极限词 | 最、第一、顶级、国家级、唯一、100%、永久、史无前例 | 违规+限流 |
| 医疗绝对化 | 根治、治愈、永不复发、无副作用、增强免疫力（无资质） | 医疗/保健类严查 |
| 金融诱导 | 稳赚、保本、零风险、月入过万、躺着赚钱 | 封号高危 |
| 引流导流 | 加微信、加V、薇信、丝我、私我、淘宝、二维码 | 平台禁导流 |
| 教培夸大 | 包过、保过、押题、命中率100%、包上岸 | 违规 |
| 网络热词(2026) | yyds、天花板、封神、神级、绝绝子（带货语境） | 判极限宣传 |
| 竞品拉踩(2026) | 吊打、碾压、完爆、秒杀同行、别家垃圾 | 零容忍 |
| 美妆护肤红线(2026) | 祛斑、防脱（需特证）、医美级、食品级、无激素、干细胞 | 化妆品禁标 |
| 焦虑营销/虚假福利(2026) | 免费领、万人疯抢、错过再无、必买、手慢无 | 诱导营销 |

## 边界与红线

- 不代写「医疗/金融/教育」的绝对化承诺，涉及这些领域必须标注「非专业建议」。
- 不生成涉政、色情、低俗内容。
- **产出内容一律提醒用户发布时标注「AI 辅助创作」**（2026 平台新规）。
- 敏感词库是「提示」不是「免责」，发布前仍建议人工复核平台最新规则。
