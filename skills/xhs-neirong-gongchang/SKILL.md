# 小红书内容工厂

把小红书内容生产整理成：**选题 → 文案 → 封面文案 → 排版 → 敏感词提示 → 人工确认**。发布是独立的外部操作。

## 何时使用

- 用户要写小红书笔记 / 种草文案 / 爆款标题 / 封面文案
- 用户要批量起号、做品牌矩阵号
- 用户要「自查文案会不会限流/踩违禁词」
- 用户准备发布内容时，先完成草稿和风险提示；外部发布需另行明确授权

## 工作流（五步）

### 1. 选题
- 蹭「低竞争 + 高搜索」关键词：用站内搜索联想词 + 低粉爆款笔记反推。
- 选题四问：给谁看？痛点是什么？我能给什么独特解法？为什么是现在？

### 2. 文案
- **标题公式**（四选一）：①数字+结果「3 步戒掉内耗」②反常识「越努力越穷的 5 个习惯」③身份+痛点「给 25 岁还在内耗的你」④提问式「为什么你总在深夜焦虑」。
- **正文结构**：钩子（前 2 行定生死）→ 痛点共鸣 → 干货/观点 → 互动引导 → 话题标签。
- **口语化改写**：短句、多用「你」、少用书面语和 AI 腔（比如「首先/其次/综上所述」一律删）。

### 3. 封面
- 竖版 3:4（1242×1656），大字标题 + 高对比色块，前 3 个字决定点击率（差 30~50%）。
- 封面文字也走敏感词自查（见第 5 步）。

### 4. 排版
- 正文分段 + emoji 分点 + 适当留白，避免一整坨；关键词埋进前 100 字。

### 5. 敏感词自查（发布前必做）
```bash
python3 bin/xhs_sensitive_check.py 笔记.md
# 输出：命中的违禁词 + 类别 + 位置 + 替换建议 + 2026 平台审核提示
```
覆盖十二类：广告法极限词 / 医疗绝对化 / 金融投资诱导 / 引流导流（含谐音变体与暗示性引流）/ 教育培训夸大 / 网络热词极限宣传(2026) / 竞品拉踩(2026) / 美妆护肤红线(2026) / 焦虑营销与虚假福利(2026) / 三品一械禁分享(2026) / 炫富与虚假人设(2026) / 金融生态公约(2026-09)。

> **2026 审核变化（务必内化）**：
> ① AI 生成文案/图片必须标注「AI 辅助创作」（社区公约 2.0 要求主动标明）；
> ② 谐音、拼音、符号隔断、拆字等规避违禁词的手段已被识别，直接合规表达；
> ③ 带货文案中「天花板/封神/yyds/绝绝子」等网络热词按极限宣传判定；「蕞有效/100%成功/彻底」等夸大词同样拦截；
> ④ 贬低竞品零容忍——2026-07 社区公约修订后，**出现可识别友商品牌名即属违规**，改为「之前用过的另一款同类产品」；
> ⑤ 化妆品禁标「无激素/0刺激/食品级/医用级」等；
> ⑥ **三品一械**（OTC 药品/保健食品/医疗器械/医疗健康服务）自 2026-02-10 起禁止在笔记与直播间分享推广；
> ⑦ **炫富与虚假人设**：「月入10w+」「三个月收入六位数」等伪造人设博流量、无实用信息的刻意炫富，会被判「宣扬奢侈浪费」（2026-05 公告）；
> ⑧ **搬运判定**：图文或文案相似度超 50% 可能被判搬运，重复发自己的旧素材同样中招；
> ⑨ 禁止以非正常手段干预内容分发、伪造数据（2026-06 公告），平台对搜索排序与 AI 问答引用以真实质量为依据；
> ⑩ **金融内容专项（2026-09-15 起）**：《社区金融生态公约》明令禁止八类内容——恶意唱衰、恶意炒作市场走势、**非法荐股**、非法金融活动、**伪造权威背书**、承诺「保本保息」等误导信息、**编造虚假投资人设**、变相导流站外；涉金融内容须做**风险提示**，AI 生成金融信息须标注；金融营销须先持牌、再通过平台专业资质认证，未经认证不得在昵称/头像/简介使用「银行/证券/期货/保险/基金」字样。

### 6. AI 标注与发布前交接
- **AI 生成内容（本 skill 产出即属此类）须向用户提示：发布时勾选「AI 辅助创作」标注**，未标注可能限流降权。
- 汇总文案、封面、标签和风险提示，等待用户确认；本 skill 本身不执行发布。

## 边界与红线

- 不代写「医疗/金融/教育」的绝对化承诺，涉及这些领域必须标注「非专业建议」。
- **三品一械（OTC 药品/保健食品/医疗器械/医疗健康服务）不生成分享推广型内容**（2026-02-10 起平台禁止）。
- **不生成金融荐股、带单、跟单类内容，不伪造金融资质或投资业绩**（2026-09-15《社区金融生态公约》八类禁内容）；涉金融内容必须附风险提示，且不得以藏头、数字暗号、生活化伪装等方式规避审核。
- **不生成炫富、伪造人设、刻意凸显消费水平的内容**；对比型内容不出现可识别友商品牌名。
- 不生成涉政、色情、低俗内容。
- **产出内容一律提醒用户发布时标注「AI 辅助创作」**（2026 平台新规）。
- 敏感词库是「提示」不是「免责」，发布前仍建议人工复核平台最新规则。
